먼저 문서를 읽고 프로젝트의 목적, 현재 개발 환경, 목표 아키텍처, 구현 우선순위를 이해해 주세요.

현재 Chrome DevTools Snippets 기반으로 HTML, CSS, JavaScript를 사용하고 있으며, 기존에 구현한 Banner Preview 및 QA Dashboard를 하나의 Tool Hub에서 독립적으로 실행하는 방향으로 개발하려고 합니다.
